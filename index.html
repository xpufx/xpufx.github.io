Paseo #

Tools and plugins for Paseo agents and plugins.

v7 tracks main (Paseo v0.7 plugin API). v8 tracks the v0.8 branches (v8 for paseo-plugin-helper) for the Paseo v0.8 runtime-entries migration: index.client.tsx / index.server.ts entries, client/ / server/ / shared/ directories, and requirements.paseo >=0.8.0. Install the line that matches your daemon.

Tools #

  • paseo-plugin-helper #

    Developer toolkit, UI design system, and lifecycle primitives for Paseo plugins. Dev library, not installed via paseo plugin add.

    GitHub npm

    v7 Paseo v0.7 (main)

    npm install github:xpufx/paseo-plugin-helper

    v8 Paseo v0.8 (v8 branch)

    npm install github:xpufx/paseo-plugin-helper#v8
  • paseo-x-comms-mcp #

    MCP server that lets agents on one Paseo daemon talk to agents on another, via relay offer or direct host.

    GitHub (mcp/, v7) GitHub (mcp/, v8) npm

    v7 standalone

    npm install -g paseo-x-comms-mcp

    v8 same npm package; plugin side uses the v0.8 branch below

Plugins #

  • paseo-top #

    Live host system resource monitor for Paseo. Pill + modal utilization view.

    GitHub (main, v7) GitHub (v0.8, v8)

    v7 Paseo v0.7

    paseo plugin add xpufx/paseo-top

    v8 Paseo v0.8 beta

    paseo plugin add xpufx/paseo-top --ref v0.8
  • paseo-x-comms #

    Cross-daemon agent communication plugin (companion to the MCP server above).

    GitHub (main, v7) GitHub (v0.8, v8)

    v7 Paseo v0.7

    paseo plugin add xpufx/paseo-x-comms

    v8 Paseo v0.8 beta

    paseo plugin add xpufx/paseo-x-comms --ref v0.8
  • paseo-mcp-tools #

    Plugin UI for checking MCP servers available to an agent session, with per-MCP actions.

    GitHub (main, v7) GitHub (v0.8, v8)

    v7 Paseo v0.7

    paseo plugin add xpufx/paseo-mcp-tools

    v8 Paseo v0.8 beta

    paseo plugin add xpufx/paseo-mcp-tools --ref v0.8
  • paseo-exfil #

    Data exfiltration plugin for Paseo (demo). v7 API only, no v8 branch. Do not install; do not trust plugins you did not write.

    GitHub (main, v7)

    v7 demo only

    paseo plugin install /path/to/paseo-exfil

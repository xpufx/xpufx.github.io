Paseo #

Tools and plugins for Paseo agents and plugins.

Tools #

  • paseo-plugin-helper #

    Developer toolkit, UI design system, and lifecycle primitives for Paseo plugins.

    GitHub npm
  • paseo-x-comms-mcp #

    MCP server that lets agents on one Paseo daemon talk to agents on another, via relay offer or direct host.

    GitHub (mcp/) npm

Plugins #

  • paseo-top #

    Live host system resource monitor for Paseo. Pill + modal utilization view.

    GitHub
  • paseo-x-comms #

    Cross-daemon agent communication plugin (companion to the MCP server above).

    GitHub
  • paseo-mcp-tools #

    Plugin UI for checking MCP servers available to an agent session, with per-MCP actions.

    GitHub
  • paseo-exfil #

    Data exfiltration plugin for Paseo (demo).

    GitHub

Apps & Scripts #

  • Uppidi Upload #

    Cross-platform file uploader for phone, tablet, desktop, and web. Upload images, video, and files to your choice of free public hosting.

    uppidi.com GitHub
  • reddit-comments-overkill #

    Browser userscript that deletes all comments of a Reddit user. Run it and leave the browser alone until done.

    GitHub
